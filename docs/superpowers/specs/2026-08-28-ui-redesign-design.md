# ZemoteS UI 大改设计(Ember 体系)

日期:2026-08-28
状态:地基定稿,逐界面设计中

## 0. 目标与裁决标准

四个目标按序执行:**统一设计语言 → 导航结构重组 → 核心体验 → 视觉现代化**。
张力裁决标准:设计语言先行——所有界面先套地基规范,再谈界面特例。
视觉气质:**内容区安静(AI 产品风)、控制区紧凑(工具风)** 的分区原则。

## 1. 信息架构(定稿)

- **三 Tab:对话 / 自动化 / 设置**;原"任务"Tab 取消,会话列表内嵌对话页左抽屉。
- **启动直达对话 Tab**:已配对设备直接进最近会话;未配对时对话区显示空态引导(添加设备大按钮 → 扫码)。
- **设备切换器**在顶栏左端(下拉切换/管理设备);设备列表不再作为独立首屏,设备管理页归入切换器的"管理设备"入口。
- **会话抽屉**(左侧):搜索、新会话、会话列表(运行中状态标记)、底部设备状态区。置顶/归档/批量管理收进抽屉顶部"管理"入口。
- **洞察面板升格**:待办/文件/后台从消息流内的 chip 折叠行改为从底部升起的独立 sheet(输入栏上方把手呼出),与消息流平级。

## 2. 色彩系统(Ember 暖炭)

### 暗色(设计基准)

| 层 | 色值 | 用途 |
|---|---|---|
| bg | `#1B1917` | 页面背景 |
| card | `#262320` | 卡片/气泡/抽屉 |
| raise | `#35302B` | 悬浮层/按下态/sheet |
| hairline | `#3A342E` | 分隔线(仅控制区;内容区靠底色差分区) |

- 主色:陶土橙 `#D97757`——仅用于交互态(链接、主按钮、选中、进行中),不大面积装饰。
- 语义色:成功 `#7FB069` / 失败 `#E5484D` / 警告 `#D4A72C` / 运行中蓝 `#6A9BD8`。
  蓝色专指"系统运行态"(思考中/处理中转圈),与主色的"可点击"语义区分。
- 文字四阶:solid `#EEE7DC` / soft `#C9BFAF` / muted `#8A8074` / faint `#5C554B`。

### 浅色(暖纸白,推导)

bg `#F7F3EC` / card `#FFFFFF` / raise `#EFE9DF`;主色加深 `#C25E3A`(白底对比度);
文字暖炭阶 `#2A241E` → `#4A4238` → `#786D5E` → `#A69B8C`;语义色同步加深校验对比度。

## 3. 字体

- **界面**:Sarasa UI SC(Regular / Bold 两档);**代码场景**(代码块/diff/工具名/终端):Sarasa Term SC(Regular)。
- 子集化打包(方案 A):GB2312 全集 + ASCII + 中英标点,fonttools 于 CI 子集化;未覆盖字符回退系统字体。
- 字阶六档:**22**(页标题)/ **17**(区块标题)/ **15**(正文重点)/ **13**(正文、消息气泡)/ **12**(次级)/ **11**(辅助信息、控制区角标)。行高 1.5。

## 4. 间距与圆角

- 4px 网格;页面边距 16,卡片内边距 12,列表行内边距 12×8,组件间隙 8/12。
- 圆角双轨:**内容区 16**(气泡 16+尾角 4、卡片 16、sheet 顶部 20);**控制区 10**(任务卡、设置行组、按钮);缩略图/头像 8。

## 5. 组件形态

- 分区:内容区靠底色差不靠边框;控制区 hairline + 小圆角。
- 按钮三型:主(陶土橙填充)、次(raise 底)、幽灵(无底主色文字)。
- 状态:图标+色双编码(色弱可用)。
- 动效仅两类:按压缩放 0.98、展开/升起过渡 200ms ease-out。

## 6. 实施顺序

对话页(含左抽屉、洞察 sheet)→ 自动化页 → 设置页(含设备管理新家)→ 二级页。
