# Zflow UI 大改设计(Ember 体系)

日期:2026-08-28
状态:已全量实施(2026-08-29),延后项清零;真机校验为最后关卡

## 0. 目标与裁决标准

四个目标按序执行:**统一设计语言 → 导航结构重组 → 核心体验 → 视觉现代化**。
张力裁决标准:设计语言先行——所有界面先套地基规范,再谈界面特例。
视觉气质:**内容区安静(AI 产品风)、控制区紧凑(工具风)** 的分区原则。

## 1. 信息架构(定稿)

- **三 Tab:对话 / 自动化 / 设置**;原"任务"Tab 取消,会话列表内嵌对话页左抽屉。
- **启动直达对话 Tab**:已配对设备直接进最近会话;未配对时对话区显示空态引导(添加设备大按钮 → 扫码)。
- **设备切换器**在顶栏左端(下拉切换/管理设备);设备列表不再作为独立首屏,设备管理页归入切换器的"管理设备"入口。
- **会话抽屉**(左侧):搜索、新会话、会话列表(运行中状态标记)、底部设备状态区。置顶/归档/批量管理收进抽屉顶部"管理"入口。
- **洞察面板升格**:待办/文件/后台从消息流内的 chip 折叠行改为从底部升起的独立 sheet(输入栏上方把手呼出),与消息流平级。

## 2. 色彩系统(Ember 暖炭)

### 暗色(设计基准)

| 层 | 色值 | 用途 |
|---|---|---|
| bg | `#1B1917` | 页面背景 |
| card | `#262320` | 卡片/气泡/抽屉 |
| raise | `#35302B` | 悬浮层/按下态/sheet |
| hairline | `#3A342E` | 分隔线(仅控制区;内容区靠底色差分区) |

- 主色:陶土橙 `#D97757`——仅用于交互态(链接、主按钮、选中、进行中),不大面积装饰。
- 语义色:成功 `#7FB069` / 失败 `#E5484D` / 警告 `#D4A72C` / 运行中蓝 `#6A9BD8`。
  蓝色专指"系统运行态"(思考中/处理中转圈),与主色的"可点击"语义区分。
- 文字四阶:solid `#EEE7DC` / soft `#C9BFAF` / muted `#8A8074` / faint `#868179`
  (faint 加深至 on bg ≥ 4.5:1,实测 4.53;旧值 `#5C554B` 仅 2.38)。

### 浅色(暖纸白,推导)

bg `#F7F3EC` / card `#FFFFFF` / raise `#EFE9DF`;主色 `#BA5A37`(白字 onPrimary
≥ 4.5:1,实测 4.56;旧值 `#C25E3A` 仅 4.24);文字暖炭阶 `#2A241E` → `#4A4238`
→ `#786D5E` → `#766E64`(faint 同样加深至 on bg ≥ 4.5:1,实测 4.54;旧值
`#A69B8C` 仅 2.47);语义色同步加深校验对比度。

## 3. 字体

- **界面**:Sarasa UI SC(Regular / Bold 两档);**代码场景**(代码块/diff/工具名/终端):Sarasa Term SC(Regular)。
- 子集化打包(方案 A):GB2312 全集 + ASCII + 中英标点,fonttools 于 CI 子集化;未覆盖字符回退系统字体。
- 字阶六档:**22**(页标题)/ **17**(区块标题)/ **15**(正文重点)/ **13**(正文、消息气泡)/ **12**(次级)/ **11**(辅助信息、控制区角标)。行高 1.5。

## 4. 间距与圆角

- 4px 网格;页面边距 16,卡片内边距 12,列表行内边距 12×8,组件间隙 8/12。
- 圆角双轨:**内容区 16**(气泡 16+尾角 4、卡片 16、sheet 顶部 20);**控制区 10**(任务卡、设置行组、按钮);缩略图/头像 8。

## 5. 组件形态

- 分区:内容区靠底色差不靠边框;控制区 hairline + 小圆角。
- 按钮三型:主(陶土橙填充)、次(raise 底)、幽灵(无底主色文字)。
- 状态:图标+色双编码(色弱可用)。
- 动效仅两类:按压缩放 0.98、展开/升起过渡 200ms ease-out。
  落地(2026-08-29):按压缩放封装为 `EmberPressable`,已应用于自动化操作条、
  任务卡、抽屉会话行(InkWell 水波保留);展开/升起用于抽屉与各 bottom sheet。

## 6. 实施顺序

设计顺序(已完成):对话页 → 自动化页 → 设置页 → 二级页,各界面均经线框迭代确认。
实施顺序:基建(theme.dart Ember token 体系 + 字体接入)→ 对话页 → 自动化页 → 设置页 →
二级页;每阶段 `flutter analyze`/`flutter test` 全绿后进入下一阶段。设计图确认后方可开工。

## 7. 各界面设计

### 7.1 对话页(定稿 2026-08-28)

**顶栏**:左端设备切换胶囊(头像+设备名,点按下拉切换/管理设备);会话名;右端模型 pill。
左缘右滑手势呼出会话抽屉。

**模型 pill**:`模型名 | 强度档名` 双段(如 `GLM-5.3 | 高`);非默认模式追加模式徽段——
计划(橙)/ 编辑(蓝)/ YOLO(红),build 默认不显示。点开面板分区:模式(build/edit/plan/yolo
四档,值与显示名随 prepareWorkspace 动态)→ 思考强度(thoughtLevels)→ 模型列表;切换即时生效。
模式可见性按风险分级:edit 仅 pill 徽(感知级);plan/yolo 追加流内状态条(权限级:计划橙条
"只读需确认"、YOLO 红条警示),模式切回默认时消失。

**消息流**:用户气泡陶土橙填充(16/尾角4)+ 状态角标(发送中/已发送/处理中/失败重试);
AI 气泡 card 底(16/尾角4);思考/工具卡更暗一档 `#211E1B` + 左侧状态 rail;回合标签独立小字行;
交互卡陶土橙描边暖底 + 选项胶囊;token 用量条 3px 细线贴输入区上方。

**会话抽屉**(左缘右滑,76% 宽):
- 顶部工作区条:橙色图标+项目名+等宽路径,点击底部升起工作区切换层(带会话数/活动标记);
  设备切换在顶栏、工作区切换在抽屉,与 bootstrap→workspaces→sessions 层级一致;
- 搜索框;虚线「＋新会话」常驻;
- 会话列表:置顶/今天/更早 三档分组(已实现 2026-08-29:置顶集经
  zcode-task.listPinnedTasks 于抽屉打开时与列表订阅并行拉取,失败容错为
  空集;「管理」置顶操作完成后自动重拉刷新分组),运行中蓝呼吸点、等待
  输入黄点;右上「管理」进入多选模式(橙色计数条+底部 置顶/归档/删除
  操作条),长按单条快捷进入;
- 底部设备状态条:在线绿点+设备数,只读,点击进设备管理页。

**洞察 sheet**(输入区上方把手上滑呼出,62% 高可拉全屏):
- 后台有任务时把手右端浮出计数徽;
- 三 Tab:待办(TODO 工具推导 + PLAN 快照计划含进度条)/ 文件(回合摘要横滑卡 + 文件行,
  点击进全屏 diff 查看器)/ 后台(任务与子代理混排时间线,转圈/✓/✗ 状态符,子代理摘要+起止时间)。

**底 Tab**:对话 / 自动化 / 设置,选中态陶土橙。

### 7.2 自动化页(定稿 2026-08-28)

- 统计卡行:全部/活跃/失败(lifecycleStatus 聚合)。
- 任务卡:标题 + 生命周期徽(活跃绿/失败红/停用灰)+ 可读调度(scheduleLabel)+ 下次/上次结果 + 启停开关。
- 详情:底部 sheet——立即运行/编辑/删除,KV 信息格(调度/模型/模式),提示词可展开,执行历史(成功行可跳转会话)。
- 编辑器:全屏表单(标题/Cron 或规则/提示词+官方模板),Ember 控件规范。
- 闲时任务队列:列表底部只读区块。



### 7.3 设置页(定稿 2026-08-28)

- 主态:外观 / 设备与连接 / 模型 / 关于 四组行组(控制区规范:card 底 + hairline + 小圆角),
  分组小标题大写间距字;字体与主题在外观组;诊断合并为单一"诊断与日志"入口(诊断日志/
  协议日志/RPC 调试器/信道浏览器二级列表)。
- 设备管理(设备列表新家,顶栏"管理设备"同跳此页):卡片式设备列表(头像/在线态/当前
  工作区)+ 扫码添加虚线按钮 + 导入导出。
- 设备详情:连接信息(地址打码)+ 重新生成二维码(作废凭据)+ 删除设备(红色隔离+确认)。

### 7.4 二级页(定稿 2026-08-28)

- 模型供应商:卡片式,状态徽三色(已启用绿/未配置黄/已停用灰+中文原因);主供应商默认
  展开模型明细(ctx/档位),其余折叠。
- 用量与配额:MCP 主额度大卡(剩余/总量+进度+重置时间)+ 五小时/每周双窗口格 + 订阅信息
  行组;阈值变色沿用(≤20% 黄、≤10% 红)。
- 诊断中心:统一入口,诊断计数与上次崩溃摘要前置;二级列表:诊断日志/协议日志/RPC 调试器/
  信道浏览器。
